# Data and pretrained model weights

Raw upstream datasets and third-party pretrained model checkpoints are
not included in this repository.

The study uses:
- MatPES-PBE for the primary analysis
- MatPES-r2SCAN for the reference-functional control
- WBM for the chemical-novelty control

The public reproducibility archive provides processed analysis artifacts,
frozen sample manifests, model-validity information, bootstrap outputs,
and figure/table source data required to trace the reported results.

Pretrained uMLIP weights must be obtained from their original
distributions. Relative checkpoint paths used during the reported
executions are retained in the inference scripts for provenance.
